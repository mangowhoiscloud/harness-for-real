Why: Spring 4.3.x bundles CGLIB 3.2.5/ASM 5.x which calls ClassLoader.defineClass() (protected) via reflection when creating @Configuration proxy subclasses. Without this, every integration test using @ContextConfiguration with a @Configuration class would fail with ExceptionInInitializerError: null. This is a one-time fix that unblocks all future integration tests (Items 13, 14, 17, 18, 19).
Discovered: Spring 4.3.x CGLIB + Java 9+ incompatibility requires --add-opens in surefire argLine. The error manifests as ExceptionInInitializerError with null cause, which makes it hard to diagnose without understanding CGLIB internals.
